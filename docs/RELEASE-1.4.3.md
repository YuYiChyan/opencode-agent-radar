# Agent Radar 1.4.3

首次公开发布 / First public release.

## 安装 / Install

```sh
opencode plugin add github:YuYiChyan/opencode-agent-radar
```

打开 OpenCode Desktop 会话，输入 `/radar`。
Open a Desktop session and use `/radar`.

也可下载 ZIP，解压后将目录加入全局 `opencode.json(c)` 的 `plugins`。详见 README。
For manual installation, extract the ZIP and add its directory to global `plugins`; see the README.

## 包含 / Highlights

- 磨砂玻璃卡堆、悬停轻抽卡与柔光 / Frosted cards, gentle hover extraction and soft lighting.
- 原生大屏与侧栏 / Native fullscreen and sidebar.
- 跟随宿主主题 / Host theme inheritance.
- 无滚动关系图自动适应 / Scroll-free auto-fit collaboration graphs.
- 真实活动与可选 AI 分析、额度环 / Actual activity, optional AI analysis and quota rings.
- 「选一个子代理，看看它有没有在摸鱼。」

相对 1.4.2，本版整理公开分发、MIT 许可、中英文文档、模拟预览数据和测试入口，运行界面逻辑保持一致。
Compared with 1.4.2, this release prepares public distribution, licensing, bilingual documentation, simulated preview data and a test entry point; runtime UI logic is unchanged.

目标版本 / Target: OpenCode Desktop **2.2.7**. Native macOS loading and Chromium preview verified; Windows/Linux native UI acceptance pending. Current interface language: Chinese.

基础功能无需 API Key；AI 分析默认关闭。下载文件可使用随附 SHA256SUMS 校验。
No API key is required for basic monitoring; AI analysis is off by default. Checksums are included for downloadable assets.
